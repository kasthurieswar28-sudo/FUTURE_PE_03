# FUTURE_PE_03
🌍 TripBuddy – AI Travel Guide Chatbot

TripBuddy is an AI-powered travel guide chatbot designed to provide day-by-day travel plans based on user inputs like destination, budget, number of days, and currency. The chatbot focuses on simple, friendly, and complete itineraries without overwhelming details.

✨ Features

Day-wise travel planning (Day 1, Day 2, etc.)

Budget range supported: 0 – 1000 (INR / USD)

Currency selection with validation

Friendly, polite, and informative tone

No hotel or time-based (morning/evening) details

Works fully through conversational AI

🛠 Tools Used

Landbot – To build and deploy the chatbot

ChatGPT – For AI prompt-based responses

Gemini – Prompt refinement and testing

Notion – Planning chatbot flow and prompts

GitHub – Documentation and version control
